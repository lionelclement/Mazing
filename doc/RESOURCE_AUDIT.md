Ce rapport est généré à partir des fichiers présents localement.

Il recherche les références textuelles dans les sources.
Cela ne remplace pas une vérification des chargements dynamiques.

Aucune ressource n'est supprimée par le patch.

## Avant toute suppression

1. Vérifier `TextureAtlases.java`.
2. Vérifier les références directes et les chargements dynamiques.
3. Ne jamais supprimer une notice de licence sans l'archiver.
4. Exécuter `./gradlew clean build run`.
5. Tester les sprites, les ombres et toutes les animations.
6. Vérifier les fichiers suivis avec `git diff --stat`.

Important : une constante d'atlas initialisée statiquement
peut charger une ressource même si la démonstration ne l'affiche pas.

Les dossiers `Dungeon-Pack/Isometric/grounds`, `objects`,
`walls`, `stairs` et `constructions` sont à considérer comme
nécessaires tant que leurs atlas sont référencés.
