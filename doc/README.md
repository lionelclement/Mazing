# Documents pédagogiques historiques

`doc/sujet-1.0.0.tex` est un sujet pédagogique universitaire associé à la
version **1.0.0** d'origine. Son intitulé ne garantit pas qu'il décrit l'API
actuelle de Mazing (`version = "1.0.1"` dans `build.gradle.kts`).

- Pour utiliser le moteur actuel, lire [`GUIDE_API.md`](GUIDE_API.md) et le
  [`README.md`](../README.md) à la racine du dépôt.
- Conserver le source `.tex` pour référence historique ; ne pas le traiter
  comme une spécification à jour sans une comparaison explicite.
- Les fichiers auxiliaires `.aux`, `.log`, `.fls`, `.fdb_latexmk`, `.out` et
  `.synctex.gz` sont des produits de compilation LaTeX, non des sources.
- Le PDF peut être conservé comme document d'archive si les droits de
  redistribution le permettent ; vérifier sa cohérence avec le `.tex`.
