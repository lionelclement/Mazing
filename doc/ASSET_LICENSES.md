## 5. Sons

Les classes Java suivantes produisent des effets sonores
synthétisés par le programme :

- `FootstepSound`
- `CrusaderCombatSounds`
- `CrusaderStaticSounds`

Le code de ces effets relève de la licence du code Mazing,
sous réserve de la titularité des droits sur ce code.

Aucun enregistrement audio tiers n'est nécessaire pour
les sons synthétisés.

Tout fichier audio ajouté à `src/main/resources/sounds/`
doit faire l'objet d'une vérification de provenance et
d'une mention de licence séparée.
